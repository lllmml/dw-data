# D3 accepted deterministic topology v2

D3 user authorization permits separately reviewed deterministic additions in a new
artifact. This decision does not change `nanjing_derived_topology_v1.md`, the frozen
interpreter or any historical artifact. Q-CONN-001 and Q-TRANSFORMER-001 remain OPEN.

Accept `SERIES_EXACT_DIRECT_V2 / 1.0.0` under the complete prerequisites in the
[D3 specification](../spec/nanjing_deterministic_topology_recovery.md). The positive
proof is redundant, identical, exact unique declarations on both sides of a uniquely
identified one-in/one-out source Switch, within one source case and the already
accepted MV model. This promotes only that narrow derived interpretation. It does
not classify exact source reference matching as confirmed real-world connectivity.

Accept `LEAF_SWITCH_REPRESENTATION_V2 / 1.0.0` under its independent prerequisites:
one unique incoming Line, exact consistent local declaration, known ordinary Switch
state and empty remote declaration. Two ports represent the declared Switch; the
remote one remains UNBOUND. The model gains no invented remote connection or junction.
This is structural representation, not proof that an external load or route exists.

The inherited E2 non-Switch endpoint mappings remain unchanged. New source Line edges
are accepted only when both terminals acquire approved local mappings; provenance
records those dependencies. No arbitrary node placement, ordering tie-break, component
bridge or Transformer winding interpretation is introduced. Any case with D2 hard
identity, ownership or explicit voltage contradiction receives no additions.

Reject the transformation of a multi-incidence Transformer into an MV junction:
the existing evidence does not prove that the incidences share a winding/port. Keep
other referenced Transformer ports, AccessPoint physical roles, broad S2 unresolved
endpoint interpretation, reverse and tie semantics NEEDS_REVIEW. Source state is never
changed: OPEN is physically present and nonconducting, CLOSED conducts, UNKNOWN lacks
the prerequisite for these two rules. Coverage improvement is not an acceptance test.

The older `proposed_series_switch_v2.md` remains a historical proposal. Its suggestion
to accept semantic-unknown ordinary S2 candidates is **not** approved by this decision.
The runtime rule review, all candidate results, overlaps, independent family impacts,
and input bindings are published with the D3 artifacts; reproduction is documented in
the [D3 guide](../guides/nanjing_deterministic_topology_recovery.md).
