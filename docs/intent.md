# Intent: 配电网算例生成与智能电网算子数据支撑框架

## 1. Background

随着智能电网相关算法的发展，负荷预测、光伏预测、故障检测、状态评估、潮流计算、优化调度等智能电网算子需要大量结构完整、格式统一、可计算的配电网数据作为测试和验证基础。

目前，甲方提供的南京市配电网公开数据主要包含电网拓扑结构信息，包括：

- 变电站
- 母线
- 开关设备
- 变压器
- 馈线等拓扑信息

但由于公开数据限制，缺少部分用于算例计算和智能算法测试的数据，包括：

- 线路电气参数
- 负荷数据
- 分布式能源数据
- 时序运行数据
- 仿真所需运行参数

因此，需要构建一个自动化的数据生成与验证框架，在保持原始配电网拓扑结构的基础上，对缺失数据进行规则化生成，形成可用于智能电网算子测试的标准化配电网算例。


---

# 2. Goal

本项目旨在构建一个面向智能电网算子的配电网算例生成框架。

系统输入：

- 甲方提供的南京配电网拓扑数据

系统输出：

- 完整配电网算例数据集
- OpenDSS 可仿真的配电网模型
- 数据质量验证报告


生成的数据应满足：

1. 保持原始拓扑结构一致；
2. 补充计算所需的电气参数；
3. 生成合理的负荷和分布式能源运行数据；
4. 支撑后续智能电网算子的开发和测试。


---

# 3. Scope

## 3.1 配电网数据解析

解析甲方提供的数据格式，包括：

- Station
- Bus
- Switch
- Transformer
- Line
- Load
- DER
- Simulation Configuration

并转换为统一内部数据模型。


---

## 3.2 电网数据生成

针对缺失的数据，采用规则驱动的方法生成。

### 设备参数生成

包括：

- 线路参数
- 变压器参数
- 设备额定参数


### 运行数据生成

包括：

- 负荷曲线
- 光伏出力曲线
- 设备运行状态


---

## 3.3 仿真模型生成

基于生成后的标准化数据：

- 自动生成 OpenDSS 模型；
- 支持潮流计算；
- 支持准静态时序仿真（QSTS）。


---

## 3.4 算子数据支撑

生成的数据作为统一数据源，为后续智能电网算子提供输入。

算子根据自身需求，通过数据适配模块获取：

- 拓扑数据；
- 时序数据；
- 状态数据；
- 潮流数据。


---

# 4. Non-goals

本项目不尝试：

1. 恢复南京真实电网运行参数；
2. 推断真实历史负荷数据；
3. 重建真实电网设备配置。


由于公开数据缺少实际运行信息，本项目生成的数据主要用于：

- 算法测试；
- 仿真验证；
- 算子开发。


生成数据需要满足：

- 规则合理；
- 物理约束满足；
- 数据可解释；

而非完全等同真实运行状态。


---

# 5. Design Principles


## 5.1 保持拓扑不变

原始拓扑数据作为可信来源。

生成过程：

允许：

- 增加缺失运行数据；
- 补充设备参数；
- 生成算例所需数据。

不主动修改：

- 原始节点关系；
- 原始设备连接关系。


---

## 5.2 数据与算法解耦

建立统一数据模型：

Raw Data

↓

Canonical Grid Model

↓

Operator Adapter / OpenDSS Adapter


避免不同算子重复处理原始数据。


---

## 5.3 规则驱动生成

所有生成过程应该基于：

- 配电网典型参数；
- 可配置规则；
- 明确假设。


避免不可解释的随机生成。


---

# 6. Success Criteria


## 数据生成

- 支持南京全部馈线批量处理；
- 自动生成完整算例数据；
- 输出甲方要求的数据格式。


## 数据质量

满足：

- 数据字段完整；
- 拓扑引用正确；
- 电气参数合理；
- 时序数据连续。


## 仿真能力

至少：

- 可以生成 OpenDSS 模型；
- 部分算例能够完成潮流计算；
- 支持准静态时序仿真。


## 工程能力

提供：

- 自动化生成程序；
- 配置化生成规则；
- 数据验证工具；
- 使用文档。


---

# 7. Future Extension

未来支持：

- 更多智能电网算子；
- 更多数据格式；
- 更复杂运行场景；
- 更精细电力系统模型。
