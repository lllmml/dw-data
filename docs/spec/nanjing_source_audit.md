## 2. 数据集概况

压缩包已按全部 CSV 逐行只读检查：

- 共 5,159 个馈线目录、61,908 个 CSV 文件；每个目录均包含 12 类 CSV。
- 所有文件均可按 UTF-8 with BOM 读取，同类文件的表头完全一致。
- 共有 5,134 条 `Feeder` 记录，25 个目录的 `Feeder` 文件只有表头。
- `Load` 和 `DER` 在所有目录中均只有表头，无数据行。
- 各类相位字段均为空；线路电气参数全部为空；站点经纬度全部为空。
- 所有 `SimConfig` 文件都包含相同的 11 个键值，不能据此认定每条馈线具有真实、独立的仿真配置。

## 3. 标识符与引用事实

### 3.1 标识符必须按字符串处理

原始 ID 最长达到 19 位。部分引用已出现科学计数法或长整数末位被舍入的迹象，例如：

- `Bus_Station_ID` 中出现 `1.13997365584593e+17`；
- 开关端点中出现与候选实体接近但不相等的长整数；
- `Bus_ID` 同时包含纯数字形式和带 `_bs` 后缀的形式。

这些是源数据事实。科学计数法转整数或“最近 ID”只能形成修复候选，不能自动成为已确认引用。

5,134 条现有 `Feeder_SourceBus` 均可在各自目录内精确匹配 Bus。该结果只确认源引用解析，不单独证明消费者所需的电气连接或仿真源配置。

### 3.2 `FromBus` / `ToBus` 是混合源引用

在同一馈线目录内按原始字符串精确匹配，端点值可命中多类实体：

| 原始字段 | Bus | Switch | Station | Transformer | AccessPoint | 未解析/零值 |
|---|---:|---:|---:|---:|---:|---:|
| `Line_FromBus` | 89,966 | 62,504 | 3,706 | 25 | 297 | 29 |
| `Line_ToBus` | 23,339 | 107,976 | 0 | 14,285 | 7,430 | 3,497 |
| `Switch_FromBus` | 39,096 | 7,868 | 1,589 | 1 | 12 | 224,150（含 163,849 个空值） |
| `Switch_ToBus` | 804 | 2,149 | 0 | 919 | 111 | 268,733（含 209,759 个空值） |

上述匹配只证明源引用关系，不证明物理电气连接。南京源数据更接近“设备/连接点混合源图”，不能仅凭命中类型认定为母线—支路拓扑。

### 3.3 重复和冲突 ID

`Switch_ID` 在 607 个算例内存在重复，共多出 1,255 行。其中：

- 330 组内容完全相同，可标记为候选重复记录；
- 489 组内容冲突，常见情况是同一 `Switch_ID` 对应不同 `ToBus`。

源文件路径和行号是区分这些记录的必要信息。冲突记录在确认治理规则前不得合并。

## 4. 运行量测的时间语义

7,804 条开关记录声明 `Switch_HasMeasurement=True`，但所有 `Switch_Meas_Timestamp` 均为空。电流、P、Q 的非空数分别为 7,803、7,756、7,755，且包含负值和明显离群值。

因此这些值目前只能解释为“时间未知的源快照值”。不得为其补造历史时间戳，也不得直接排列成时间序列。功率正负方向尚未确认。

## 5. 原始仿真配置

每个目录都包含下列相同配置：

| `Config_Key` | 原始值 | 当前可陈述含义 |
|---|---|---|
| `SimulationMode` | `Snapshot` | 声明的仿真模式 |
| `Algorithm` | `Newton-Raphson` | 声明的求解方法 |
| `BaseFrequency` | `50` | 基准频率，Hz |
| `BaseVoltage_kV` | `10.5` | 声明的源基准电压，kV |
| `SourceBus` | `SUB_10KV` | 原始源母线引用，当前未解析 |
| `OutputVoltageBus` | `SUB_10KV` | 原始观测母线引用，当前未解析 |
| `MaxIterations` | `100` | 最大迭代次数 |
| `Tolerance` | `0.0001` | 收敛容差，精确语义待目标仿真规范确认 |
| `MVAsc3` | `500` | 三相短路容量，MVA |
| `MVAsc1` | `450` | 单相短路容量，MVA |
| `UnitSystem` | `Metric` | 单位制声明 |

这些值可以按源值导入，但不能标记为已验证参数，也不能据此判定 OpenDSS 就绪。

## 6. 当前数据质量结论

- 数据可以在保留原值、空值、记录位置和质量事件的前提下完成忠实导入。
- 导入完成不表示物理连接已确认。
- 当前数据缺少相位、线路参数、负荷、DER 和大量变压器参数；这是源数据质量与完整性事实，不是 Canonical schema 无效。
- 当前审计不判断 Snapshot、QSTS 或 OpenDSS 就绪；此类判断必须绑定具体 Adapter 版本和场景合同。

## 7. 待甲方或源系统确认

1. `FromBus` / `ToBus` 实际表示母线、设备邻接、端口，还是抽象连接点？
2. 是否存在未发生精度损失的权威 ID 对照表？长 ID 精度损失发生在哪个导出环节？
3. 相位编码和功率正负方向分别采用什么约定？
4. 开关量测对应哪个时刻或时间基准？没有时间信息时是否只允许作为无时标快照？
5. `EarthingSwitch_State` 是当前状态还是正常状态？
6. Station 坐标采用什么坐标系？
7. 变压器 44,596 行异常目录是否为测试数据、重复导出或有效资产？
8. `Tolerance` 的准确求解语义是什么？`SUB_10KV` 如何对应真实源 Bus？
9. Load/DER 与 AccessPoint、Transformer 或其他业务表之间是否有权威关联资料？
